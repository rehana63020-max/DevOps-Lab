# Experiment 10
## To Install and Explore Selenium for Automated Testing

### Aim
To install and explore Selenium for automating web browser testing.

### Software Required
- Python
- Selenium
- Google Chrome
- Visual Studio Code

### Installation
Install Selenium using the command:

pip install selenium

### Procedure
1. Install Python.
2. Install Selenium using pip.
3. Install Google Chrome.
4. Create a Python file.
5. Import Selenium WebDriver.
6. Open the Chrome browser using Selenium.
7. Perform a Google search automatically.
8. Close the browser.

### Program
The Python program opens Google Chrome, searches for Selenium Automation and closes the browser.

### Result
Successfully installed and explored Selenium for automated browser testing.
