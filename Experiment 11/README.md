# Experiment 11
## Write a Simple Program in JavaScript and Perform Testing Using Selenium

### Aim
To write a simple JavaScript program and test it using Selenium WebDriver.

### Software Required
- JavaScript
- Node.js
- Selenium WebDriver
- Google Chrome
- Visual Studio Code

### Procedure
1. Create a simple JavaScript addition program.
2. Create an HTML webpage.
3. Install Node.js.
4. Install Selenium WebDriver and Mocha.
5. Write Selenium test scripts.
6. Open the webpage using Chrome.
7. Enter two numbers and click the Add button.
8. Verify the result using Selenium.

### Installation Commands

npm init -y

npm install selenium-webdriver

npm install --save-dev mocha

### Execution Command

npx mocha test.js

### Expected Output

10 + 20 = 30

Test Passed Successfully.

### Result
Successfully developed a JavaScript program and performed automated testing using Selenium.
