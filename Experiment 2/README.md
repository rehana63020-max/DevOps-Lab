# Experiment 2: Explore Git and GitHub Commands

## AIM

To explore commonly used Git and GitHub commands for version control and collaboration in software development.

## DESCRIPTION

Git is a distributed version control system used to track changes in files and source code. GitHub is an online platform used to host Git repositories and collaborate with other developers.

## Common Git and GitHub Commands

### 1. Initialize a Git Repository

```bash
git init
```

Creates a new Git repository in the current directory.

### 2. Check Repository Status

```bash
git status
```

Displays the status of files in the working directory.

### 3. Add Files to the Staging Area

```bash
git add <file-name>
```

Adds the specified file to the staging area.

### 4. Commit Changes

```bash
git commit -m "commit message"
```

Saves staged changes in the repository with a descriptive message.

### 5. Check Commit History

```bash
git log
```

Displays the commit history of the repository.

### 6. Discard Uncommitted Changes

```bash
git restore <file-name>
```

Discards unstaged changes in a file. Use carefully because discarded changes may be lost.

### 7. Create a New Branch

```bash
git branch <branch-name>
```

Creates a new branch in the repository.

### 8. Switch to Another Branch

```bash
git switch <branch-name>
```

Switches to the specified branch.

### 9. Merge Branches

```bash
git merge <branch-name>
```

Merges the specified branch into the current branch.

### 10. Push Changes to GitHub

```bash
git push origin <branch-name>
```

Uploads local commits to the remote GitHub repository.

### 11. Clone a Repository

```bash
git clone <repository-url>
```

Downloads a remote repository to the local computer.

### 12. Pull Changes from GitHub

```bash
git pull origin <branch-name>
```

Fetches and integrates changes from the remote repository.

### 13. Create a Pull Request

Open the repository on GitHub, select the branch containing your changes, and choose the option to create a pull request. A pull request allows collaborators to review and discuss changes before merging them.

## RESULT

Thus, commonly used Git and GitHub commands for version control and collaboration were explored.
