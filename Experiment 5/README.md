# Experiment 5
## Demonstrate CI and CD using Jenkins

### Aim
To demonstrate Continuous Integration and Continuous Deployment using Jenkins.

### Tools Required
- Jenkins
- Visual Studio Code
- Git
- GitHub

### Procedure
1. Create a project in VS Code.
2. Create an HTML file.
3. Create a Jenkinsfile.
4. Open Jenkins.
5. Create a new Pipeline project.
6. Configure the project to use the Jenkinsfile.
7. Build the pipeline.
8. Observe Build, Test and Deploy stages.

### Result
CI/CD pipeline was demonstrated successfully using Jenkins.
