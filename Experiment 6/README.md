# Experiment 6
## Explore Docker Commands for Container Management

### Aim
To explore and execute basic Docker commands for container management.

### Software Required
- Docker Desktop
- Visual Studio Code
- Windows OS

### Docker Commands

1. Check Docker Version
   docker --version

2. Download an Image
   docker pull hello-world

3. Display Docker Images
   docker images

4. Run a Container
   docker run hello-world

5. Display Running Containers
   docker ps

6. Display All Containers
   docker ps -a

7. Start a Container
   docker start container_id

8. Stop a Container
   docker stop container_id

9. Remove a Container
   docker rm container_id

10. Remove an Image
    docker rmi hello-world

### Procedure
1. Install and open Docker Desktop.
2. Open VS Code terminal.
3. Check Docker version.
4. Download the required Docker image.
5. Run the container.
6. View running and stopped containers.
7. Start and stop containers using Docker commands.
8. Remove containers and images when no longer required.

### Result
Successfully explored basic Docker commands for container management.
